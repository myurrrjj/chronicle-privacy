# Chronicle — legal pages

Hosted with GitHub Pages.

- Privacy Policy: https://myurrrjj.github.io/chronicle-privacy/
- Data Deletion: https://myurrrjj.github.io/chronicle-privacy/data-deletion.html

These pages describe the Chronicle Android app (package `com.myurrrjj.chronicle`).
Chronicle has no server and no account. All processing happens on the device; the only outbound traffic is
a single photo coordinate sent to the system geocoder for a place name, and map tiles from OpenFreeMap —
see the privacy policy, section 4.
